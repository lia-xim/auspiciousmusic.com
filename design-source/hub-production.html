Terms used across this hub

Collect All and Save
The command that copies every referenced sample into the project folder — the single step that makes a session portable.
Freezing
Rendering a track to audio in place so its plug-ins stop consuming CPU while remaining reversible.
Stem
A submix of one element or group, delivered separately so it can be balanced again downstream.
Production music
Music written for licensing into media rather than for release, usually delivered with alternate lengths and mixes.
