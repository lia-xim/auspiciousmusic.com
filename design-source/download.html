The Spy Guitar

Ableton Live Pack
Published 2013 – 2017

A sampled electric guitar instrument. The original files were not transferred with the domain and their licence position is unresolved, so they are not redistributed. The technique is fully documented in a current guide you can follow with your own recordings.

Modern alternative Resource page

Bang My Twister

Max for Live device
Published 2014

A device for switching banks on the DJ TechTools MIDI Fighter Twister. The mapping is still published and maintained by DJ TechTools, so this page links there rather than rehosting a copy that would immediately go out of date.

External source DJ TechTools

Fender VI Ableton Sampler Live Pack

Ableton Live Pack
Published 2014

A sampled baritone instrument built from a Fender VI. Rights to the source recordings are unverified and the instrument is not redistributed. A rebuild guide is planned but not published — this entry will change when it is, not before.

Unavailable

NoisR

Max for Live instrument
Announced 2014

A noise-designer device developed by a third party and covered on this domain at the time of its release. It was never owned by this publication; any current version remains with its own developer.

What a published download will carry

These fields are required before any file is served from this domain. They are listed here so the standard is public before there is anything to apply it to.

Version
Semantic version, incremented on every change
Compatibility
Host application and minimum version, tested
Platform
macOS / Windows, with the versions actually verified
Owner
Who created it and who holds the rights today
Licence
Named licence, linked in full
Checksum
SHA-256, published beside the file
Security scan
Scan date, re-run on every version change
Support status
Maintained, archived, or unsupported — stated plainly
