Bang My Twister

A Max for Live device for switching banks on the DJ TechTools MIDI Fighter Twister, published on this domain in 2014 by the former operator. The original mapping is still maintained by DJ TechTools, so this page points there rather than rehosting a copy.

What the original project was

The MIDI Fighter Twister has sixteen encoders. A Live set almost always has more than sixteen parameters worth reaching, which is the problem bank switching exists to solve: each encoder addresses a different parameter depending on which page is active.

Bang My Twister was a small Max for Live device that handled that switching from inside the Live set rather than from the controller's own configuration utility. It was published here alongside a visualiser project and circulated through the controller community of the period.

Why external sources still point here

The device was listed in the DJ TechTools mapping archive, which is still online and still maintained. That is a live, verifiable reference rather than an archived one — the reason this address returns a page instead of a redirect, and the reason the download status here reads as external rather than unavailable.

Current status

The mapping is available from DJ TechTools, who publish and maintain it. This publication does not host a copy: a rehosted mapping goes stale the moment the original is updated, and the version here would quietly become the wrong one.

Compatibility has not been re-tested by us. The device dates from 2014 and Live has had several major versions since. A current compatibility test is planned; until it has been run, this page does not claim the device still works.

Rights and attribution

The device was created and published by the former operator of this domain; the controller and its mapping archive belong to DJ TechTools. Auspicious Music is an independent publication under new ownership since 2026 and claims no part of either. Nothing here should be read as a continuation of, or endorsement by, the former operator.

How the same thing is done now

Bank switching no longer needs a bespoke device in most cases. The controller's own configuration utility handles multiple banks natively, and Live's mapping has improved considerably since 2014. Where a set genuinely needs switching driven from inside Live, a small Max device remains the way to do it — the approach is covered in the Ableton hub.
